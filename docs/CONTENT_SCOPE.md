# 内容范围与编辑原则

本版收录16位代表人物、32条年号记录，保留三个设计方向。不是中国历代皇帝全集。

各人的年号名称列全；谥号采用标注来源的全称与主要版本，尊号仅列经核对的实例，不声称穷尽历次授号。早期汉代年号命名存在追记讨论；日期范围为涉及的公元年份，不替代月日历表。明确区分在位年份、改元年份、初谥、加谥、改庙号和末段简称。私人追称不得混入官定庙谥。

资料与字段来源见网页各人物链接及 data/history-catalogue.json。乾隆全谥依《清史稿·高宗本纪》篇首文字，保留与故宫网页省略文字不同的说明。顺治的故宫网页卒谥与《清史稿》1736年加尊谥分别列示。

修改人物资料时编辑 data/history-catalogue.json。npm run build 将该数据注入页面并复制公开 JSON，避免展示与下载数据不一致。页面原创关系图均为解释示意图，不是文物画像。正式内容审校仍可依据页面给出的资料入口逐条进行。
